1 — Executive Summary

اقرأ هذه الفقرة أولاً — هي ما يحتاجه أي AI أو مهندس جديد ليفهم المشروع في 60 ثانية:

PRIME-Factory Software Platform is a dual-mode monitoring dashboard built with Python + Dash/Plotly. It strictly separates Real Hardware Mode (reading live data from Arduino Uno via Serial) from Industrial Simulation Mode (demonstrating the value of PdM/EMS/MES on realistic industrial scenarios).

Real Mode: Reflects the physical hardware (GA25-370 Motor, ACS712, ADXL345, DS18B20, TCRT5000). No ESP32 in this phase.

Simulation Mode: Focuses on the Fertilizer Industry (3 machines) and Packaging Industry (3 machines). Uses a sequential execution engine: Run "Without PRIME-Factory" → Finish → Run "With PRIME-Factory" → Finish → Display Dynamic Comparison Report. Financial losses are calculated dynamically based on specific machine and fault profiles, not fixed global constants.

1.1 Core Design Principles

  1. Strict Mode Separation: The UI must start with a Landing Page. The user chooses either Real Mode or Simulation Mode. They do not mix.
  2. Sequential Comparison (Simulation): Never show "With" and "Without" systems simultaneously on the same timeline. The user must watch the failure unfold (Without), then watch the prevention (With), then see the final comparison report.
  3. Dynamic Financial Modeling: No hardcoded global constants (e.g., "5000 EGP/hour"). Every machine and fault has its own profile containing specific downtime costs, repair costs, energy waste rates, and scrap costs.
  4. Hardware Fidelity (Real Mode): The Real Mode dashboard must only display data and KPIs that are physically measurable by the Arduino setup defined in Hardware Constitution v6.1.
  5. Realistic Simulation Signatures: Simulation data must not be "dumb random numbers". It must mimic real sensor behavior (e.g., current spikes with noise, gradual temperature rise, specific vibration frequency shifts).

2 — System Architecture & Data Flow

2.1 Real Mode Pipeline (Arduino Only)

[Arduino Uno] 
   │ (USB Serial @ 9600 baud)
   │ Payload: "STATE,RPM,UNITS,I_A,V_V,T_C,VIB,SETPOINT\n"
   ▼
[Python Backend (pyserial)]
   │ Parses CSV string → Validates types
   ▼
[Local SQLite Cache (Optional but recommended)]
   │ Stores last 300 seconds of data for chart stability
   ▼
[Dash Frontend]
   │ Updates KPI Cards & Plotly Charts every 1 second

⚠ Note: ESP32 and MQTT are completely excluded from Real Mode in this phase.

2.2 Simulation Mode Pipeline

[User UI] → Selects: Industry (Fertilizer) → Machine (e.g., Granulator) → Fault (e.g., Jam)
   ▼
[Simulation Engine (Python)]
   │ Loads `MACHINE_PROFILES` dictionary for dynamic costs.
   │ Generates time-series data (0 to 60 seconds) with realistic noise and fault signatures.
   ▼
[Sequential Player]
   │ Step 1: Play "Without PRIME" data stream → Update UI → End.
   │ Step 2: Play "With PRIME" data stream → Update UI → End.
   ▼
[Comparison Engine]
   │ Calculates dynamic financial/technical loss for both scenarios.
   │ Renders Side-by-Side Comparison Dashboard.

5.1 Calculation Logic for the Report

Without PRIME-Factory:
Loss_Without = (time_to_failure × downtime_cost) + repair_cost_without + (time_to_failure × units_lost × scrap_cost)

With PRIME-Factory:
Loss_With = (time_to_detection × downtime_cost) + repair_cost_with + (time_to_detection × units_lost × scrap_cost)

Savings = Loss_Without - Loss_With

import serial
import threading
from datetime import datetime
from dataclasses import dataclass
from typing import Optional, List
from collections import deque

@dataclass
class SensorReading:
    timestamp: datetime
    state: str
    rpm: float
    units: int

    voltage_v: float
    temp_c: float
    vib_rms: float

class SerialReader:
    """
    Reads Arduino Serial data in a background thread.
    Format: STATE,RPM,UNITS,I_A,V_V,T_C,VIB,SETPOINT
    Baud: 9600
    """
    
    def __init__(self, port: str = "COM3", baud: int = 9600, buffer_size: int = 300):
        self.port = port
        self.baud = baud
        self.buffer_size = buffer_size
        self.readings: deque = deque(maxlen=buffer_size)
        self.is_connected = False
        self._thread: Optional[threading.Thread] = None
        self._stop_event = threading.Event()
        self._serial: Optional[serial.Serial] = None
    
    def start(self):
        """Start background reading thread."""
        try:
            self._serial = serial.Serial(self.port, self.baud, timeout=1)
            self.is_connected = True
            self._stop_event.clear()
            self._thread = threading.Thread(target=self._read_loop, daemon=True)
            self._thread.start()
        except serial.SerialException as e:
            print(f"[SerialReader] Connection failed: {e}")
            self.is_connected = False
    
    def stop(self):
        """Stop reading thread."""
        self._stop_event.set()
        if self._serial and self._serial.is_open:
            self._serial.close()
        self.is_connected = False
    
    def _read_loop(self):
        """Background loop: parse lines and append to buffer."""
        while not self._stop_event.is_set():
            try:
                if self._serial and self._serial.is_open:
                    line = self._serial.readline().decode('utf-8', errors='ignore').strip()
                    if line:
                        reading = self._parse_line(line)
                        if reading:
                            self.readings.append(reading)
            except Exception as e:
                print(f"[SerialReader] Error: {e}")
    
    def _parse_line(self, line: str) -> Optional[SensorReading]:
        """
        Parse: STATE,RPM,UNITS,I_A,V_V,T_C,VIB,SETPOINT
        Example: RUNNING,218.5,47,0.842,11.95,42.3,0.125,220
        """
        try:
            parts = line.split(',')
            if len(parts) != 8:
                return None
            
            return SensorReading(
                timestamp=datetime.now(),
                state=parts[0].strip(),
                rpm=float(parts[1]),
                units=int(parts[2]),
                current_a=float(parts[3]),
                voltage_v=float(parts[4]),
                temp_c=float(parts[5]),
                vib_rms=float(parts[6]),
                setpoint_rpm=int(parts[7])
            )
        except (ValueError, IndexError):
            return None
    
    def get_latest(self) -> Optional[SensorReading]:
        """Get most recent reading."""
        if self.readings:
            return self.readings[-1]
        return None
    
    def get_last_n(self, n: int) -> List[SensorReading]:
        """Get last N readings."""
        return list(self.readings)[-n:]

import math
import random
from datetime import datetime, timedelta
from typing import List, Dict, Tuple
from backend.machine_profiles import MACHINE_PROFILES

class SimulationEngine:
    """
    Generates realistic time-series data for a specific machine + fault.
    Two modes: 'without_pf' (catastrophic failure) and 'with_pf' (early detection).
    """
    
    def __init__(self, machine_id: str, fault_id: str, duration_s: int = 60):
        self.machine = MACHINE_PROFILES[machine_id]
        self.fault = self.machine["faults"][fault_id]
        self.duration_s = duration_s
        self.injection_time_s = self.fault["injection_time_s"]
    
    def generate_without_pf(self) -> List[Dict]:
        """
        Timeline A: No PRIME-Factory.
        Fault progresses → catastrophic failure → high losses.
        """
        data = []
        baseline_rpm = self.machine["rated_rpm"]
        baseline_current = self.machine["rated_current_a"] * self.machine["typical_load_pct"]
        baseline_vib = self.machine["baseline_vibration_g"]
        baseline_temp = self.machine["baseline_temp_c"]
        
        for t in range(self.duration_s):
            if t < self.injection_time_s:
                # Normal operation
                rpm = baseline_rpm + random.uniform(-5, 5)
                current = baseline_current + random.uniform(-0.5, 0.5)
                vib = baseline_vib + random.uniform(-0.01, 0.01)
                temp = baseline_temp + random.uniform(-0.5, 0.5)
                state = "RUNNING"
            else:
                # Fault progression (gradual degradation)
                fault_duration = t - self.injection_time_s
                progress = fault_duration / (self.duration_s - self.injection_time_s)
                
                # RPM drops gradually
                rpm = baseline_rpm * (1 - progress * 0.8) + random.uniform(-10, 10)
                
                # Current spikes (with noise)
                current_spike = self.fault["current_spike_a"] - baseline_current
                current = baseline_current + current_spike * progress + random.uniform(-1, 1)
                
                # Vibration increases
                vib = baseline_vib * (1 + self.fault["vibration_increase_factor"] * progress)
                vib += random.uniform(-0.02, 0.02)
                
                # Temperature rises
                temp = baseline_temp + self.fault["temp_increase_rate_c_per_min"] * (fault_duration / 60) * 10
                temp += random.uniform(-0.5, 0.5)
                
                state = "RUNNING"
                if progress > 0.9:
                    state = "FAULT"
                    rpm = 0
                    current = self.fault["current_spike_a"]
            
            data.append({
                "t_s": t,
                "timestamp": (datetime.now() + timedelta(seconds=t)).isoformat(),
                "rpm": round(max(0, rpm), 1),
                "current_a": round(max(0, current), 2),
                "voltage_v": round(380 + random.uniform(-5, 5), 1),
                "power_w": round(current * 380 * 0.85 / 1000, 2),
                "temp_c": round(temp, 1),
                "vibration_rms_g": round(max(0, vib), 3),
                "energy_wh": round(current * 380 * 0.85 / 3600, 4),
                "units_produced": int(self.machine["production_rate_units_per_hour"] / 3600 * t * (rpm/baseline_rpm)),
                "oee_pct": round(85 * (rpm/baseline_rpm), 1),
                "state": state,
                "alert": None
            })
        
        return data
    
    def generate_with_pf(self) -> List[Dict]:
        """
        Timeline B: With PRIME-Factory.
        Early detection → planned maintenance → minimal losses.
        """
        data = []
        baseline_rpm = self.machine["rated_rpm"]
        baseline_current = self.machine["rated_current_a"] * self.machine["typical_load_pct"]
        baseline_vib = self.machine["baseline_vibration_g"]
        baseline_temp = self.machine["baseline_temp_c"]
        
        # Detection time (much earlier)
        detection_time_s = int(self.fault["time_to_detection_with_pf_min"] * 60)
        if detection_time_s < 5:
            detection_time_s = 5  # Minimum 5 seconds for demo
        
        for t in range(self.duration_s):
            if t < self.injection_time_s:
                # Normal operation
                rpm = baseline_rpm + random.uniform(-5, 5)
                current = baseline_current + random.uniform(-0.5, 0.5)
                vib = baseline_vib + random.uniform(-0.01, 0.01)
                temp = baseline_temp + random.uniform(-0.5, 0.5)
                state = "RUNNING"
                alert = None
            elif t < self.injection_time_s + detection_time_s:
                # Fault starts but not yet detected
                fault_duration = t - self.injection_time_s
                progress = fault_duration / detection_time_s
                
                rpm = baseline_rpm * (1 - progress * 0.1) + random.uniform(-5, 5)
                current = baseline_current + (self.fault["current_spike_a"] - baseline_current) * progress * 0.3
                vib = baseline_vib * (1 + self.fault["vibration_increase_factor"] * progress * 0.5)
                temp = baseline_temp + self.fault["temp_increase_rate_c_per_min"] * (fault_duration / 60)
                state = "RUNNING"
                alert = None
            else:
                # Detected! System alerts, maintenance planned
                rpm = baseline_rpm + random.uniform(-2, 2)  # Back to normal after maintenance
                current = baseline_current + random.uniform(-0.3, 0.3)
                vib = baseline_vib + random.uniform(-0.01, 0.01)
                temp = baseline_temp + random.uniform(-0.3, 0.3)
                state = "RUNNING"
                alert = f"⚠ {self.fault['name']} detected at t={self.injection_time_s + detection_time_s}s. Planned maintenance initiated."
            
            data.append({
                "t_s": t,

                "current_a": round(max(0, current), 2),

                "oee_pct": round(85 * (rpm/baseline_rpm), 1),
                "state": state,
                "alert": alert

class SequentialPlayer:
    """
    Plays simulation data point-by-point with configurable speed.
    Supports callbacks for UI updates.
    """
    
    def __init__(self, speed_multiplier: float = 1.0):
        self.speed_multiplier = speed_multiplier
        self.current_data: List[Dict] = []
        self.current_index: int = 0
        self.is_playing: bool = False
        self.on_update: Optional[Callable] = None
        self.on_complete: Optional[Callable] = None
    
    def load_data(self, data: List[Dict]):
        """Load time-series data."""
        self.current_data = data
        self.current_index = 0
    
    def set_callbacks(self, on_update: Callable, on_complete: Callable):
        """Set update and completion callbacks."""
        self.on_update = on_update
        self.on_complete = on_complete
    
    def play(self):
        """Play data point-by-point."""
        self.is_playing = True
        self.current_index = 0
        
        for i, point in enumerate(self.current_data):
            if not self.is_playing:
                break
            
            self.current_index = i
            
            if self.on_update:
                self.on_update(point, i, len(self.current_data))
            
            # Wait based on speed multiplier
            time.sleep(1.0 / self.speed_multiplier)
        
        self.is_playing = False
        
        if self.on_complete:
            self.on_complete()
    
    def stop(self):
        """Stop playback."""
        self.is_playing = False
    
    def get_current_point(self) -> Optional[Dict]:
        """Get current data point."""
        if 0 <= self.current_index < len(self.current_data):
            return self.current_data[self.current_index]
        return None

class MESCalculator:
    """Calculate MES metrics from live Arduino data."""
    
    def __init__(self):

        self.cycle_start_time = None
        self.cycle_times = []
        self.setpoint_rpm = 220
    
    def update(self, reading: SensorReading):
        """Update MES metrics with new reading."""
        # Count units (every 8 pulses = 1 revolution = 1 unit)
        # This is already done in Arduino firmware
        self.units_total = reading.units
        
        # Calculate cycle time (time per revolution)
        if reading.rpm > 0:
            cycle_time_s = 60.0 / reading.rpm
            self.cycle_times.append(cycle_time_s)
            # Keep last 60 cycle times
            if len(self.cycle_times) > 60:
                self.cycle_times.pop(0)
        
        # OEE Calculation
        availability = self._calculate_availability()
        performance = self._calculate_performance(reading.rpm)
        quality = self._calculate_quality(reading.current_a)
        oee = availability * performance * quality
        
        return {
            "units_total": self.units_total,
            "avg_cycle_time_s": sum(self.cycle_times) / len(self.cycle_times) if self.cycle_times else 0,
            "oee_pct": round(oee * 100, 1),
            "availability_pct": round(availability * 100, 1),
            "performance_pct": round(performance * 100, 1),
            "quality_pct": round(quality * 100, 1)
        }
    
    def _calculate_availability(self) -> float:
        """Availability = Run Time / Planned Time."""
        # Simplified: assume 100% availability if running
        return 1.0
    
    def _calculate_performance(self, actual_rpm: float) -> float:
        """Performance = (Ideal Cycle Time × Total Units) / Run Time."""
        if self.setpoint_rpm == 0:
            return 0
        return min(actual_rpm / self.setpoint_rpm, 1.0)
    
    def _calculate_quality(self, current_a: float) -> float:
        """Quality = Good Units / Total Units."""
        # Assume quality is good if current is within normal range
        if 0.02 <= current_a <= 0.10:  # Normal operating range
            return 1.0
        elif current_a > 0.10:
            return 0.9  # Slight degradation
        else:
            return 0.5  # Idle or fault

class PdMCalculator:
    """Calculate PdM metrics from live Arduino data."""
    
    def __init__(self, baseline_vibration_g: float = 0.05):
        self.baseline_vibration_g = baseline_vibration_g
        self.vibration_history = []
        self.temp_history = []
    
    def update(self, reading: SensorReading) -> dict:
        """Update PdM metrics with new reading."""
        self.vibration_history.append(reading.vib_rms)
        self.temp_history.append(reading.temp_c)
        
        # Keep last 60 readings
        if len(self.vibration_history) > 60:
            self.vibration_history.pop(0)
        if len(self.temp_history) > 60:
            self.temp_history.pop(0)
        
        # Vibration trend
        vib_trend = self._calculate_trend(self.vibration_history)
        vib_ratio = reading.vib_rms / self.baseline_vibration_g if self.baseline_vibration_g > 0 else 0
        
        # Temperature trend
        temp_trend = self._calculate_trend(self.temp_history)
        
        # Health score (0-100)
        health_score = self._calculate_health_score(vib_ratio, temp_trend)
        
        return {
            "vibration_rms_g": round(reading.vib_rms, 3),
            "vibration_baseline_g": self.baseline_vibration_g,
            "vibration_ratio": round(vib_ratio, 2),
            "vibration_trend": vib_trend,
            "temp_c": round(reading.temp_c, 1),
            "temp_trend": temp_trend,
            "health_score": round(health_score, 1),
            "alert_level": self._get_alert_level(vib_ratio, temp_trend)
        }
    
    def _calculate_trend(self, history: List[float]) -> str:
        """Calculate trend: 'stable', 'increasing', 'decreasing'."""
        if len(history) < 10:
            return "stable"
        
        recent_avg = sum(history[-10:]) / 10
        older_avg = sum(history[-20:-10]) / 10
        
        if recent_avg > older_avg * 1.1:
            return "increasing"
        elif recent_avg < older_avg * 0.9:
            return "decreasing"
        else:
            return "stable"
    
    def _calculate_health_score(self, vib_ratio: float, temp_trend: str) -> float:
        """Calculate health score (0-100)."""
        score = 100.0
        
        # Vibration penalty
        if vib_ratio > 3.0:
            score -= 50
        elif vib_ratio > 2.0:
            score -= 30
        elif vib_ratio > 1.5:
            score -= 15
        
        # Temperature trend penalty
        if temp_trend == "increasing":
            score -= 20
        
        return max(0, score)
    
    def _get_alert_level(self, vib_ratio: float, temp_trend: str) -> str:
        """Get alert level: 'normal', 'warning', 'critical'."""
        if vib_ratio > 3.0 or (vib_ratio > 2.0 and temp_trend == "increasing"):
            return "critical"
        elif vib_ratio > 1.5 or temp_trend == "increasing":
            return "warning"
        else:
            return "normal"

class RuleBasedAI:
    """
    Rule-based anomaly detection (Layer 1).
    Fast, no false positives, works without ML model.
    """
    
    def __init__(self):
        self.current_threshold_a = 0.9  # JAM threshold
        self.temp_threshold_c = 70.0
        self.vibration_threshold_g = 0.15
        self.voltage_low_threshold_v = 9.0
    
    def check_anomaly(self, reading: SensorReading) -> dict:
        """Check for anomalies based on rules."""
        anomalies = []
        severity = "normal"
        
        # Current check
        if reading.current_a >= 1.4:
            anomalies.append("INSTANT OVERCURRENT")
            severity = "critical"
        elif reading.current_a >= self.current_threshold_a:
            anomalies.append("JAM DETECTED")
            severity = "high"
        
        # Temperature check
        if reading.temp_c >= self.temp_threshold_c:
            anomalies.append("OVERTEMPERATURE")
            severity = "critical"
        
        # Vibration check
        if reading.vibration_rms_g >= self.vibration_threshold_g:
            anomalies.append("HIGH VIBRATION")
            if severity != "critical":
                severity = "high"
        
        # Voltage check
        if reading.voltage_v <= self.voltage_low_threshold_v and reading.voltage_v > 0.5:
            anomalies.append("UNDERVOLTAGE")
            if severity != "critical":
                severity = "medium"
        
        return {
            "anomalies": anomalies,
            "severity": severity,
            "has_anomaly": len(anomalies) > 0
        }

def generate_scenario(machine_id: str, fault_id: str, duration_s: int = 60) -> dict:
    """Generate realistic time-series data for a specific machine + fault."""
    machine = MACHINE_PROFILES[machine_id]
    fault = machine["faults"][fault_id]
    
    baseline_rpm = machine["rated_rpm"]
    baseline_current = machine["rated_current_a"] * machine["typical_load_pct"]
    baseline_vib = machine["baseline_vibration_g"]
    baseline_temp = machine["baseline_temp_c"]
    voltage = 380.0
    
    injection_t = fault["injection_time_s"]
    data_points = []
    cumulative_energy_wh = 0.0
    cumulative_units = 0
    units_per_second = machine["production_rate_units_per_hour"] / 3600.0
    
    for t in range(duration_s):
        if t < injection_t:
            # Normal operation with small noise
            rpm = baseline_rpm + random.uniform(-5, 5)
            current = baseline_current + random.uniform(-1, 1)
            vib = baseline_vib + random.uniform(-0.01, 0.01)
            temp = baseline_temp + random.uniform(-0.3, 0.3)
            state = "RUNNING"
            alert = None
        else:
            # Fault progression
            fault_duration = t - injection_t
            progress = min(fault_duration / (duration_s - injection_t), 1.0)
            
            # Different fault signatures
            if fault_id == "mechanical_jam":
                rpm = max(0, baseline_rpm * (1 - progress * 1.2))
                current = baseline_current + (fault["current_spike_a"] - baseline_current) * min(progress * 1.5, 1.0)
                vib = baseline_vib * (1 + fault["vibration_increase_factor"] * progress * 2)
                temp = baseline_temp + fault["temp_increase_rate_c_per_min"] * (fault_duration / 60) * 15
            elif fault_id == "unbalance":
                rpm = baseline_rpm + random.uniform(-3, 3)
                current = baseline_current + random.uniform(-0.5, 0.5)
                vib = baseline_vib * (1 + fault["vibration_increase_factor"] * progress)
                temp = baseline_temp + random.uniform(-0.2, 0.2)
            elif fault_id == "thermal_overload":
                rpm = baseline_rpm * (1 - progress * 0.1)
                current = baseline_current * (1 + progress * 0.3)
                vib = baseline_vib * (1 + progress * 0.5)
                temp = baseline_temp + fault["temp_increase_rate_c_per_min"] * fault_duration
            elif fault_id == "voltage_sag":
                rpm = baseline_rpm * (1 - progress * 0.25)
                current = baseline_current * (1 + progress * 0.4)
                vib = baseline_vib * (1 + progress * 0.3)
                temp = baseline_temp + random.uniform(0, 2)
                voltage = 380 * (1 - progress * 0.15)
            elif fault_id == "overload":
                rpm = baseline_rpm * (1 - progress * 0.15)
                current = baseline_current + (fault["current_spike_a"] - baseline_current) * progress
                vib = baseline_vib * (1 + progress)
                temp = baseline_temp + fault["temp_increase_rate_c_per_min"] * fault_duration * 0.5
            elif fault_id == "loosening":
                rpm = baseline_rpm + random.uniform(-10, 10)
                current = baseline_current + random.uniform(-2, 2)
                vib = baseline_vib * (1 + fault["vibration_increase_factor"] * progress * 1.5)
                temp = baseline_temp + random.uniform(-0.5, 0.5)
            elif fault_id == "speed_droop":
                rpm = baseline_rpm * (1 - progress * 0.3)
                current = baseline_current * (1 + progress * 0.2)
                vib = baseline_vib * (1 + progress * 0.4)
                temp = baseline_temp + random.uniform(0, 1)
            
            # Determine state and alert
            if progress > 0.9 and fault_id in ["mechanical_jam", "thermal_overload"]:
                state = "FAULT"
                alert = f"🛑 {fault['name'].upper()}"
            elif progress > 0.7:
                state = "RUNNING"
                alert = "🔴 CRITICAL"
            elif progress > 0.4:
                state = "RUNNING"
                alert = "⚠⚠ High severity"
            elif progress > 0.1:
                state = "RUNNING"
                alert = "⚠ Anomaly detected"
            else:
                state = "RUNNING"
                alert = None
        
        # Calculate power and energy
        power_kw = (current * voltage * 0.85) / 1000.0
        energy_this_second = power_kw / 3600.0  # kWh per second
        cumulative_energy_wh += energy_this_second * 1000  # convert to Wh
        cumulative_units += units_per_second * (rpm / baseline_rpm)
        
        # OEE calculation
        availability = 1.0 if state == "RUNNING" else 0.0
        performance = rpm / baseline_rpm
        quality = 1.0 if abs(rpm - baseline_rpm) / baseline_rpm < 0.1 else 0.9
        oee = availability * performance * quality * 100
        
        data_points.append({
            "t_s": t,
            "rpm": round(max(0, rpm), 1),
            "current_a": round(max(0, current), 2),
            "voltage_v": round(voltage, 1),
            "power_kw": round(power_kw, 2),
            "temp_c": round(temp, 1),
            "vibration_g": round(max(0, vib), 3),
            "energy_wh": round(cumulative_energy_wh, 3),
            "units": int(cumulative_units),
            "oee_pct": round(max(0, min(100, oee)), 1),
            "state": state,
            "alert": alert
        })
    
    return {
        "scenario_id": f"{machine_id}_{fault_id}",
        "industry": machine["industry"],
        "equipment": machine["name"],
        "equipment_id": machine_id,
        "fault_type": fault["name"],
        "fault_id": fault_id,
        "duration_s": duration_s,
        "fault_injection_time_s": injection_t,
        "detection_time_with_pf_s": int(fault["time_to_detection_with_pf_min"] * 60),
        "detection_time_without_pf_s": int(fault["time_to_failure_without_pf_min"] * 60),
        "financial_constants": {
            "downtime_cost_egp_per_hour": machine["downtime_cost_egp_per_hour"],
            "energy_waste_cost_egp_per_minute": machine["energy_waste_cost_egp_per_min"],
            "scrap_cost_egp_per_unit": machine["scrap_cost_egp_per_unit"],
            "maintenance_repair_egp": fault["repair_cost_with_pf_egp"],
            "maintenance_replace_egp": fault["repair_cost_without_pf_egp"],
            "production_rate_units_per_hour": machine["production_rate_units_per_hour"]
        },
        "baseline": {
            "rated_rpm": baseline_rpm,
            "rated_current_a": machine["rated_current_a"],
            "typical_load_pct": machine["typical_load_pct"],
            "baseline_vibration_g": baseline_vib,
            "baseline_temp_c": baseline_temp,
            "voltage_v": voltage
